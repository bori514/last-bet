# 13 · THE LAST BET — 온라인 태블릿 프로토타입

## 실행
Node.js 18 이상 설치 후 프로젝트 폴더에서:

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속. 같은 와이파이의 태블릿은 서버 컴퓨터의 내부 IP 주소와 포트 3000으로 접속할 수 있습니다. 서로 다른 네트워크에서 플레이하려면 Node.js/WebSocket을 지원하는 호스팅 서비스에 이 프로젝트를 배포해야 합니다. 이 ZIP은 배포 완료된 공개 웹사이트가 아닙니다.

## 현재 구현
- 3~6인 방 생성 및 6자리 코드 입장
- 시작금 200만 원, 13라운드, 라운드 참가비 5만 원
- 플레이어별 독립 공개/비공개 1~13 카드 세트, 소진 후 재사용 없음
- 본인 공개 카드 숨김, 본인 비공개 카드만 표시, 상대 공개 카드 표시
- 폴드/체크/콜/5만 원 단위 레이즈, 턴 순서, 승부 정산
- 동점 팟 균등 분배, 최종 순위, 자본 0원 관전

## 알려진 한계 (중요)
- 현재 프로토타입은 **사이드 팟을 지원하지 않습니다**. 자본이 부족한 콜(올인)이 가능한 상태에서 정산은 단일 팟으로 처리되어 정식 포커와 다릅니다. 실제 경쟁 테스트 전 사이드 팟을 구현해야 합니다.
- 중도 이탈 시 재접속 복구, 서버 재시작 후 방 복원, 플레이어 인증, 자동 턴 타이머 없음
- 기본 참가비도 잔액 범위 내에서만 차감. 5만 원 미만 자본 처리 등은 추후 확정 필요
- 각 라운드 배팅 단계는 한 번이며 베팅 라운드를 여러 차례 반복하는 텍사스 홀덤 전체 구조는 아님
- 서버 메모리에 게임 저장. 실서비스 보안 및 부정행위 방지 검토 필요
- 실제 돈 거래 기능 없음
